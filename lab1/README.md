## Перелік знайдених проблем та метод виправлення

1. **Відсутній `lang` на `<html>`**
   * *Чому це важливо:* Скрінрідери не знають, з якою інтонацією та правилами мови читати текст, якщо мова не вказана явно.
   * *Як виправлено:* Додано `<html lang="uk">`.

2. **`<img>` без `alt` (Аватар та Скриншот)**
   * *Чому це важливо:* Користувачі з вадами зору не отримують жодної інформації про графічний контент, скрінрідер просто зачитує назву файлу.
   * *Як виправлено:* Додано змістовні атрибути `alt=""` з описами зображень.

3. **Заголовки в неправильному порядку (h1 → h3 → h2)**
   * *Чому це важливо:* Ламається логічне дерево документа. Користувачі, які переміщуються по сайту за допомогою заголовків, втрачають орієнтацію.
   * *Як виправлено:* Змінено `<h3>Освіта</h3>` на `<h2>Освіта</h2>`.

4. **Список через `<br>` замість `<ul>` (Розділи "Освіта" та "Технології")**
   * *Чому це важливо:* Текст сприймається як суцільний рядок. Скрінрідери не оголошують перелік як список і не кажуть кількість елементів у ньому.
   * *Як виправлено:* Дані загорнуто в семантичні теги `<ul>` та `<li>`.

5. **Контраст інформації передається тільки кольором**
   * *Чому це важливо:* Люди з дальтонізмом не зрозуміють статус виконання завдання (червоний/зелений), якщо статус маркується лише кольором шрифту.
   * *Як виправлено:* За допомогою класу `.visually-hidden` додано прихований пояснювальний текст ("Проблема:", "Доступно:"), який зачитується скрінрідером.

6. **`<a>` без `href`, з `onclick`**
   * *Чому це важливо:* Таке посилання неможливо сфокусувати за допомогою клавіші `Tab`. Воно повністю випадає з навігації клавіатурою.
   * *Як виправлено:* Додано повноцінний `href="mailto:..."`.

7. **`<div onclick>` як «кнопка»**
   * *Чому це важливо:* Тег `<div>` не є інтерактивним. Він не має фокусу з клавіатури, і скрінрідери не оголошують його користувачу як кнопку, яку можна натиснути.
   * *Як виправлено:* Замінено на семантичний тег `<button type="button">`.

8. **`<input>` без `<label>`**
   * *Чому це важливо:* Коли користувач ставить фокус у поле, placeholder зникає. Скрінрідери часто не зачитують placeholder як назву поля.
   * *Як виправлено:* Створено елемент `<label>`, пов'язаний через `id/for`. Візуально його приховано за допомогою CSS для збереження дизайну сторінки.

9. **`<button>` без `type` атрибута**
   * *Чому це важливо:* Браузери по-різному інтерпретують кнопку без типу. Вона може автоматично намагатися перезавантажити сторінку чи надіслати неіснуючу форму.
   * *Як виправлено:* Явно вказано атрибути `type="submit"` та `type="button"`.

10. **`target="_blank"` без `rel="noopener"`**
    * *Чому це важливо:* Це створює серйозну безпекову вразливість (*reverse tabnabbing*), дозволяючи відкритій сторінці маніпулювати батьківською вкладкою через об'єкт `window.opener`.
    * *Як виправлено:* До посилань додано атрибут `rel="noopener"`
